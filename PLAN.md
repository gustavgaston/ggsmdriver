# GGSMDriver — plan (milestone 0, for review)

Standalone, reusable stepper module: STM32 + TMC2209, one power input, USB-C,
4-wire motor terminal. KiCad schematic and PCB are generated by scripts in
`gustavgaston/autopcb`; the design itself lives in this repo.

## What already exists

- `roaring/automato/middleware/ggstepper/` in `gustavgaston/works` — working TMC2209 firmware
  (Arduino, AVR Uno only: direct port registers, Timer1, bit-banged UART).
  It homes by StallGuard on the **DIAG** pin, sets IRUN/IHOLD/VSENSE over UART,
  and has a configurator + velocity finder. It needs a port to STM32, but the
  logic (planner, homing, Automato adapter) carries over.
- `autopcb/` — `pcbai` package (~1.3k lines): reads a board open in KiCad via
  the IPC API, DRC wrapper, geometry/scoring, controlled placement moves.
  Nothing generates schematics or PCBs yet. Only project is Intertrack
  (STM32H7R3, unrelated). Targets KiCad 10.0.4.
- Adafruit TMC2209 breakout (product 6121) — EAGLE files at
  github.com/adafruit/Adafruit-TMC2209-Breakout-PCB. Key values from its .sch:
  sense resistors 0.05 Ω 0.25 W (≈2 A max), 22 nF CPI–CPO, 0.22 µF VCP,
  0.22 µF/50 V + 22 µF/50 V electrolytic on VM, 10 µF on 5VOUT and VCCIO,
  10 k VREF trimmer fed via 33 k from 5VOUT, CLK_IN to GND (internal clock),
  ENABLE pulled **low** by 20 k (driver on by default), UART pin direct,
  SPREAD solder jumper, MS1/MS2 broken out, STEP/DIR LEDs.

## MCU pick (proposed): STM32G0B1CBT6

| | G0B1CBT6 (pick) | F103C8T6 | C071 |
|---|---|---|---|
| Core | M0+ 64 MHz, 128 kB | M3 72 MHz, 64 kB | M0+ 48 MHz, 128 kB |
| USB without crystal | yes (HSI48) | no, 8 MHz crystal | yes |
| Flash over USB from ROM | yes, DFU (BOOT button) | no, UART only → custom bootloader via ST-Link once | yes, DFU |
| Package | LQFP48, hand-solderable | LQFP48 | LQFP/TSSOP |
| Arduino (STM32duino) | yes, used on BTT TMC2209 boards | yes | newer, support less proven |

G0B1 is what BigTreeTech uses next to TMC2209s (SKR Mini E3 V3), so the
pairing is proven, and USB-C + DFU means no programmer is ever needed.
C071 is cheaper but younger; F103 needs a crystal and a one-time ST-Link.

## Milestones (pause after each)

0. **Survey + plan** (this file). Done 2026-10-16.
1. **Circuit spec + BOM** — `GGSMDriver/requirements.md` block by block
   (power, regulator, MCU, USB-C, TMC2209 per Adafruit, connectors), pin map,
   part numbers. No KiCad yet. Done 2026-10-16.
2. **Schematic generator** — autopcb grows a small script set that writes a
   `.kicad_sch` from a Python block description using KiCad's standard
   libraries; ERC with kicad-cli in the cloud container. Output:
   `GGSMDriver/kicad/` project you open in KiCad 10. Done 2026-10-16 (ERC clean in KiCad 10).
3. **PCB generator** — outline, mounting holes, footprint placement by script,
   autoroute (Freerouting via DSN) or leave routing to you if it's poor; DRC.
   Done 2026-10-16 as a practice run (fully routed, no DRC errors); Gustav will
   rework routing, placement and silkscreen later.
4. **Fab outputs + firmware bring-up** — gerbers/BOM/placement for the fab
   (generated 2026-10-16, `pcbai.fab`);
   ggstepper ported to STM32 (USB serial, UART config, STEP/DIR timer).

Intertrack in autopcb is left untouched; new code goes beside it.
