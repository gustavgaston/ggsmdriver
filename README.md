# GGSMDriver

A small, reusable stepper driver module: STM32G0B1 + TMC2209, one 9–24 V supply
(barrel jack or 2-pole terminal), USB-C for serial and firmware upload, and a
4-pole terminal for a 4-wire motor. The board is 4 layers, 55×45 mm, with every
part on top, for JLCPCB assembly.

## Layout

| Path | What |
|---|---|
| `requirements.md` | Circuit spec, pin map, parts with LCSC numbers, confirmed decisions |
| `PLAN.md` | Milestones |
| `HANDOFF.md` | Current state and how to regenerate everything (start here when resuming) |
| `hardware/ggsmdriver.py` | The design as Python: parts, pin→net map, PCB placement |
| `hardware/ggsmdriver.kicad_sym` | Custom TMC2209 symbol |
| `kicad/` | Generated KiCad project (schematic, PCB, PDF) and `reports/` |
| `kicad/fab/` | JLCPCB gerbers zip, BOM and placement (CPL) files |

The KiCad files are generated by [autopcb](https://github.com/gustavgaston/autopcb)
from `hardware/ggsmdriver.py`; hand edits in KiCad are lost on regeneration.
They are KiCad 7 format and open in KiCad 10.
